# ToolkitLife

**[toolkitlife.com](https://toolkitlife.com)** — 370+ free online tools that run entirely in your browser. No signup, no upload, no data stored.

## Tools

- **Developer:** JSON Formatter, Regex Tester, JWT Decoder, Base64 Encoder, Diff Checker, CSS Generators, and 25+ more
- **Design:** Image Compressor, Image Resizer, Background Remover, Color Palette Generator, Meme Generator, and more
- **PDF:** Merge PDF, Split PDF, Compress PDF, PDF to Word, JPG to PDF, PNG to PDF
- **Video:** Video Compressor, Video to GIF, Screen Recorder, Video Watermark Remover
- **Finance:** Mortgage, Loan, Retirement, Investment, Tax, and 40+ calculators
- **Health:** BMI, TDEE, Calorie, Macro, Body Fat, and 20+ calculators
- **Utility:** Resume Builder, Invoice Generator, Digital Signature, Text to Speech, Unit Converter

## Privacy

All tools run client-side in your browser. No files are uploaded to any server. No accounts, no tracking, no data collection.

## Tech Stack

- Next.js + TypeScript + Tailwind CSS
- Canvas API for image/video processing
- Web Speech API for text-to-speech
- FFmpeg WASM for video compression
- Tesseract.js for OCR
- PDF.js for PDF processing
